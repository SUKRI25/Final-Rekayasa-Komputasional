## 🐛 Troubleshooting Cepat

### Problem: Halaman tidak muncul
```
❌ Issue: index.html tidak buka
✅ Solusi:
  1. Pastikan browser sudah installed (Chrome/Firefox)
  2. Double-click ulang index.html
  3. Atau drag index.html ke browser
  4. Atau: Buka Live Server via VS Code
```

### Problem: Search tidak ada filmnya
```
❌ Issue: Film list kosong/loading
✅ Solusi:
  1. Tunggu sebentar (data loading)
  2. Lihat console (F12 → Console tab)
  3. Cari message: "Data loaded: X movies"
  4. Jika error: refresh (Ctrl+Shift+R)
```

### Problem: GA sangat lambat
```
❌ Issue: Loading lama (> 1 menit)
✅ Solusi:
  1. Kurangi Populasi ke 15
  2. Kurangi Generasi ke 10-15
  3. Close browser tabs lain
  4. Jalankan di browser lain (Chrome lebih cepat)
```

### Problem: GA tidak menghasilkan rekomendasi
```
❌ Issue: Hasil kosong setelah GA
✅ Solusi:
  1. Pastikan sudah select film dulu
  2. Lihat console untuk error
  3. Try dengan film berbeda
  4. Refresh halaman penuh (Ctrl+Shift+R)
```

**Lebih detail? Lihat file USAGE_GUIDE.md!**
